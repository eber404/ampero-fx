# Ampero FX Catalog

Browse Hotone Ampero effects and check which pedalboards support them, using information from Hotone's official manuals and effect lists.

[Open the catalog](https://eber404.github.io/ampero-fx/).

## Search the catalog

Type words in **Search** and press **Enter** to add each word as a tag. Search by effect name, description, or pedalboard. Results must match all active tags (AND), regardless of capitalization.

For example, enter `delay mini` to find effects that match both words.

Click a tag to remove it. Press **Backspace** with an empty search field to remove the last tag.

Click **Clear** to remove all tags and any text in the search field, then browse the full catalog again.
